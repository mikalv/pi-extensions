# auth-providers-suite

Shared provider/account/auth foundation for Pi runtimes, orchestration work, memory/TUI integrations, and future usage/quota tooling.

## Current focus
- provider registry
- account registry
- auth strategy types
- provider resolution
- groundwork for special-case providers
